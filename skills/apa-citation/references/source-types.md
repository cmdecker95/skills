# APA7 — Additional Source Types

Reference templates and examples for less common source types. Consult this file when the main SKILL.md does not cover the source.

---

## Social Media Posts

### General format (Twitter/X, Instagram, LinkedIn, Facebook posts)

```
Author, A. A. [@username]. (Year, Month Day). First 20 words of the post, including any hashtags or emoji [Description of media attached]. Platform. URL
```

- Use real name + [@handle] if known; use [@handle] alone if real name is unknown
- The "title" of a social media post is simply the first 20 words of the post text, italicized
- Include a descriptor in brackets for any attached media: `[Image]`, `[Video]`, `[Photograph]`, `[Infographic]`, `[Tweet]`
- For profiles/pages (not individual posts): add `Retrieved Month Day, Year, from URL` because profiles change over time

**Tweet/X post example:**

```
NASA [@NASA]. (2024, February 14). Valentines from space: Our Hubble telescope captured this "cosmic heart" — two interacting galaxies [Image] [Tweet]. X. https://x.com/NASA/status/1234567890
```

**Instagram post example:**

```
National Geographic [@natgeo]. (2024, March 5). Beneath the surface: A diver explores the world's largest cave system in Mexico [Photograph]. Instagram. https://www.instagram.com/p/XXXXXXXX/
```

**Facebook post example:**

```
World Health Organization. (2023, November 20). Today is World Children's Day. Every child deserves to grow up healthy and safe [Video]. Facebook. https://www.facebook.com/WHO/posts/xxxxxxx
```

**TikTok video:**

```
Author, A. A. [@username]. (Year, Month Day). First 20 words of caption or video description [Video]. TikTok. URL
```

## Podcast Episode

```
Host, A. A. (Host). (Year, Month Day). Title of episode (Season X, Episode XX) [Audio podcast episode]. In *Podcast Series Name*. Production Company. URL
```

- If the host also produced it, just list one role
- For an entire podcast series (not a single episode), use the series title as the work

**Example:**

```
Harris, S. (Host). (2023, October 15). The nature of consciousness (No. 327) [Audio podcast episode]. In *Making Sense with Sam Harris*. Waking Up. https://www.samharris.org/podcasts/making-sense-episodes/327-the-nature-of-consciousness
```

## Dissertation or Thesis

### From a database (ProQuest, etc.)

```
Author, A. A. (Year). *Title of dissertation in sentence case* [Doctoral dissertation, University Name]. Database Name. URL
```

### Unpublished / institutional repository

```
Author, A. A. (Year). *Title of thesis* [Master's thesis, University Name]. Institutional Repository Name. URL
```

**Example:**

```
Chang, L. (2022). *Social media use and adolescent identity formation: A longitudinal study* [Doctoral dissertation, Stanford University]. ProQuest Dissertations & Theses Global. https://www.proquest.com/docview/2849302043
```

## Conference Paper or Presentation

### Published in proceedings

```
Author, A. A., & Author, B. B. (Year, Month Day–Day). *Title of paper* [Paper presentation]. Conference Name, City, Country. https://doi.org/xxxxx
```

### Unpublished / slides only

```
Author, A. A. (Year, Month Day). *Title of presentation* [PowerPoint slides]. Conference Name. URL
```

**Example:**

```
LeCun, Y. (2023, June 18). *Self-supervised learning: The dark matter of intelligence* [Keynote presentation]. CVPR 2023, Vancouver, Canada.
```

## Magazine Article

```
Author, A. A. (Year, Month Day). Title of article in sentence case. *Magazine Name*, *volume*(issue), pages. URL
```

- Very similar to newspaper articles; use date format appropriate to publication frequency

**Example:**

```
Roose, K. (2024, March). The ChatGPT revolution, one year later. *Wired*, *32*(3), 44–51.
```

## Encyclopedia or Dictionary Entry

### Online reference work (regularly updated, like Wikipedia)

```
Article title. (Year, Month Day). In *Encyclopedia/Dictionary Name*. Publisher/Website. Retrieved Month Day, Year, from URL
```

- Include retrieval date because content changes

**Example (Wikipedia):**

```
Climate change. (2024, March 12). In *Wikipedia*. https://en.wikipedia.org/wiki/Climate_change
```

Note: Wikipedia is generally not appropriate for academic citation. Point this out to the user if relevant.

### Static online or print reference work

```
Author, A. A. (Year). Entry title in sentence case. In A. B. Editor (Ed.), *Encyclopedia of Something* (Vol. X, pp. xx–xx). Publisher.
```

## Blog Post

```
Author, A. A. (Year, Month Day). Title of post in sentence case. *Blog Name*. URL
```

**Example:**

```
Brown, B. (2023, September 4). The courage to be vulnerable: What I've learned in 20 years of research. *Brené Brown*. https://brenebrown.com/blog/2023/09/04/the-courage-to-be-vulnerable/
```

## Film / Movie

```
Director, A. A. (Director). (Year). *Title of film* [Film]. Production Company.
```

- For streaming: add the platform after production company, e.g., `. Netflix.`
- If director is unknown, use the production company in the author slot

**Example:**

```
Nolan, C. (Director). (2023). *Oppenheimer* [Film]. Universal Pictures.
```

## TV Series Episode

```
Writer, A. A. (Writer), & Director, B. B. (Director). (Year, Month Day). Title of episode (Season X, Episode X) [TV series episode]. In C. C. Producer (Executive Producer), *Series Name*. Production Studio.
```

**Example:**

```
Gilligan, V. (Writer & Director). (2013, September 29). Felina (Season 5, Episode 16) [TV series episode]. In V. Gilligan (Executive Producer), *Breaking Bad*. High Bridge Entertainment.
```

## ChatGPT / Generative AI

APA treats AI-generated text similarly to personal communication when the output cannot be retrieved. However, when the platform preserves a shareable link, it is cited like a software tool.

```
OpenAI. (Year). *ChatGPT* (Version / date of response) [Large language model]. https://chat.openai.com
```

For a specific response you are quoting in the text:

> In the text, describe the prompt and note when the response was generated: "When asked about X, ChatGPT generated the following response (OpenAI, 2024)…"

**Exam[118;1:3uple:**

```
OpenAI. (2024). *ChatGPT* (GPT-4, April 2024 version) [Large language model]. https://chat.openai.com
```

## Government Document / Legislation

### Standard government report

Follow the Report template in the main SKILL.md.

### Statute / Law

```
Name of Act, Volume Source § Section Number (Year). URL
```

**Example:**

```
Americans with Disabilities Act of 1990, Pub. L. No. 101-336, 104 Stat. 327 (1990). https://www.ada.gov/law-and-regs/ada/
```

## Software / App / Dataset

```
Author, A. A., or Company Name. (Year). *Software or dataset name* (Version X.X) [Software/Dataset]. Publisher or Repository. https://doi.org/xxxxx
```

**Example:**

```
R Core Team. (2023). *R: A language and environment for statistical computing* (Version 4.3.1) [Software]. R Foundation for Statistical Computing. https://www.R-project.org
```

## Preprint (arXiv, bioRxiv, SSRN, etc.)

```
Author, A. A., & Author, B. B. (Year). Title of preprint in sentence case. *Preprint Repository*. https://doi.org/xxxxx
```

Note: note in your text that this is a preprint and has not undergone peer review.

**Example:**

```
Vaswani, A., Shazeer, N., Parmar, N., Uszkoreit, J., Jones, L., Gomez, A. N., Kaiser, Ł., & Polosukhin, I. (2017). Attention is all you need. *arXiv*. https://arxiv.org/abs/1706.03762
```

## "Retrieved from" — When to Include It

Only include `Retrieved Month Day, Year, from URL` (rather than just the bare URL) when:

- The content is likely to change over time and is **not** archived
- Examples: wikis, social media profiles, live dashboards, frequently updated pages

For all other online sources, just end with the URL.
